# Catch & Clean

Game 2D bertema SDG (pengelolaan sampah) dibuat dengan Unity 6.3 LTS.

## Cara bermain
- A/D atau panah: gerak
- Spasi: menembak limbah B3
- Klik atau sentuh sampah organik/plastik untuk mengumpulkan

## Cara membuka project
1. Clone repository ini.
2. Di Unity Hub: Add > Add project from disk.
3. Buka dengan Unity 6.3 LTS.
